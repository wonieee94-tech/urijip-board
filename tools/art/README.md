# 놀이터 사진풍 그림

`public/img/*.webp` 는 `tools/art/src/*.jpg` 를 `python3 tools/art/make-art.py` 로 줄이고(WebP), 하늘을 투명하게 하거나
초록 배경을 지워(비행기·먹구름) 만든 것입니다.

## 출처·사용 조건
- `src/` 의 그림 8장(낮 하늘, 밤 하늘, 구름 위 바다, 낮/밤 공항, 비행기, 먹구름, 달리기 경기장)은 2026-11-18 이 프로젝트를 위해
  이미지 생성 도구(Grok Bot)로 새로 만든 그림입니다. 실제 사진이나 스톡 사진, 다른 사람의 작품을 가져오지 않았고,
  실제 공항·항공사 로고를 그대로 쓰지 않았습니다(공항·경기장은 가상의 장소, 비행기에는 글씨·로고 없음, 관중은 흐릿한 가상 인물).
- "세윤항공" 글씨는 그림이 아니라 놀이 화면(canvas)에서 아이 이름으로 그려 넣습니다.
- 가족 놀이용 사이트에서 자유롭게 써도 되지만, 다른 곳에 다시 쓰거나 팔 때는 이미지 생성 서비스의 이용 약관을 한 번 확인해 주세요.

## 다시 만들기
```
pip install pillow numpy
python3 tools/art/make-art.py
```
그림을 바꾸면 `public/sw.js` 의 `VERSION` 을 올려 주세요.
